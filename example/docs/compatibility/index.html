Compatibility

jQStar 1.1 preserves the stable root and modular runtime entries and adds optional shared stores. The testing harnesses, CSP runtime, and Turbo and htmx bridges are tested from the packed tarball, not from repository-only imports.

Supported environments

  • jQuery >=4.0.0 <5.
  • Node 24 or newer and npm 11 or newer for Node consumers and project tooling.
  • Current installed Chromium, Firefox, and WebKit browser fixtures.
  • ESM, CommonJS, browser modules, and the root UMD/no-build distribution.
  • Ordinary HTML documents and same-origin frame documents.

Shadow-root applications are not supported. Turbo support is >=8.0.21 <8.1.0; htmx support is >=2.0.0 <2.1.0. Both hosts are optional and injected explicitly.

Version boundaries

The npm package version is 1.1.0. The plugin registrar remains independently versioned as 0.1.0, and the finite CSP grammar remains jqstar-csp-expression/1. A package release does not silently change either contract.

The root entry retains the recorded 0.1 behavior, including real jQuery, trusted JavaScript expressions, and the default Datastar request profile. Read the 1.0 migration guide for additions and unchanged defaults.

Lifecycle policy

The current 1.x minor receives fixes. The previous 1.x minor receives security fixes for six months after the next minor ships. Unsupported entries fail explicitly; they are not kept alive through hidden aliases. Security handling is described in the security policy.
