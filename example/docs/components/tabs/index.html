API Reference

Contract Purpose
data-jqs="tabs" The component root; data-value stores the active stable value.
data-part="list" The labeled tab list and orientation owner.
data-part="trigger" A tab whose value matches one panel.
data-part="panel" The associated tab panel.
data-activation="manual" Moves focus without changing panels until Enter or Space.
data-orientation="vertical" Uses Up and Down instead of Left and Right movement.

Keyboard Interactions

  • Left / RightMoves through horizontal tabs and activates on focus by default.
  • Up / DownMoves through a vertical tab list.
  • Home / EndMoves to the first or last enabled tab.
  • Enter / SpaceActivates the focused tab when manual activation is configured.

Changes emit cancelable jquery-star:tabs:before-change and final jquery-star:tabs:change events. Call $.star.ui.tabs.activate('#settings-tabs', 'security') or the equivalent @ui.tabs.activate action for programmatic selection.
