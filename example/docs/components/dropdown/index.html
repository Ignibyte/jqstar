Dropdown

A popup action menu with managed positioning, roving focus, typeahead, selection, disabled items, checkbox and radio state, dismissal, and trigger focus return.

dropdown-menu.html 
<div data-jqs="menu" data-align="end">
  <button data-part="trigger">Actions</button>
  <div data-part="content" aria-label="Project actions">
    <button data-part="item" data-value="edit">Edit</button>
    <button
      data-part="checkbox-item"
      data-value="preview"
      data-checked="true"
    >
      Show preview
    </button>
    <div data-part="separator"></div>
    <button data-part="item" data-value="delete" data-disabled>
      Delete
    </button>
  </div>
</div>

API Reference

Contract Purpose
data-jqs="menu" The positioned menu root.
data-part="trigger" The button that opens and receives focus after dismissal.
data-part="content" The generated menu surface and accessible menu owner.
item / checkbox-item / radio-item Selectable item types with stable data-value identities.
data-disabled Keeps an item focusable for discovery but prevents selection.
data-side / data-align Preferred floating placement; collision handling remains automatic.

Keyboard Interactions

  • Enter / SpaceOpens the menu or selects the focused item.
  • Arrow Up / DownMoves focus among items and wraps at either end.
  • Home / EndMoves to the first or last menu item.
  • TypeaheadMoves to an item whose label starts with the typed characters.
  • EscapeCloses the menu and restores focus to its trigger.

The cancelable jquery-star:menu:select event can prevent a selection. Add data-close-on-select="false" when a menu should remain open. Programmatic and named actions are available under $.star.ui.menu and @ui.menu.*.
