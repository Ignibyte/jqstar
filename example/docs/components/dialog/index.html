Dialog

A modal window that interrupts the user with important content and expects a response.

Edit profile

Review the profile before saving your changes.
dialog.html 
<button
  data-jqs="button"
  aria-haspopup="dialog"
  data-on:click="@ui.dialog.open('#account-dialog', '#dialog-cancel')"
>
  Edit account
</button>

<dialog id="account-dialog" data-jqs="dialog" data-close-on-backdrop>
  <div data-part="content">
    <header data-part="header">
      <h2 data-part="title">Edit account</h2>
      <p data-part="description">Review changes before saving.</p>
    </header>
    <footer data-part="footer">
      <button id="dialog-cancel" data-on:click="@ui.dialog.close('cancelled')">
        Cancel
      </button>
      <button data-on:click="@ui.dialog.close('saved')">Save</button>
    </footer>
  </div>
</dialog>

API Reference

Attribute Element Description
<dialog data-jqs="dialog"> Dialog The native modal owner and component root.
data-part="content" Container The styled surface inside the browser top layer.
title / description Heading and text Parts used to establish accessible dialog relationships.
data-part="footer" Container Optional action layout.
data-close-on-backdrop Dialog Opts into dismissal when the native backdrop is pressed.
data-variant="sheet" Dialog Uses the same dialog behavior in a side-docked composition.

Keyboard Interactions

  • Enter / SpaceActivates the ordinary trigger button.
  • Tab / Shift+TabMoves through focusable controls while native modality contains focus.
  • EscapeCloses the dialog unless the cancel event is prevented, then restores trigger focus.

Opening emits cancelable jquery-star:dialog:before-open and final open events; closing follows the same before/final pattern. JavaScript can call $.star.ui.dialog.open() and close() directly.
