The component contract

  • Native elements first: buttons, forms, details, dialog, tables, links, progress, and other platform semantics remain real.
  • Stable anatomy: data-part identifies structural slots without coupling behavior to decorative classes.
  • Visible state: documented attributes such as data-state, data-value, and ARIA state remain inspectable.
  • Keyboard and focus: composite widgets implement their documented WAI-ARIA interaction model and focus ownership.
  • Server replacement: newly patched roots enhance automatically and removed roots release owned behavior.
  • Source ownership: the CLI copies ordinary HTML that applications can edit; jQStar supplies the reusable runtime.
