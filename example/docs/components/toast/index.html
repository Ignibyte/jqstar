Toast

A temporary, non-modal notification with accessible announcements, optional actions, pausable duration, keyboard access, and pointer swipe dismissal.

toast.html 
<button
  data-jqs="button"
  data-on:click="@ui.toast.show({
    title: 'Saved',
    description: 'Your changes are live.',
    variant: 'success'
  })"
>
  Save changes
</button>

<div
  data-jqs="toast-viewport"
  aria-label="Notifications (F8)"
></div>

API Reference

Option Purpose
title Required concise notification heading.
description Optional supporting detail.
variant default, success, warning, or danger.
duration Dismissal delay in milliseconds. Passive toasts default to five seconds.
action An optional authored action; action toasts remain until dismissed unless duration is explicit.
data-jqs="toast-viewport" The page-level notification and keyboard-focus owner.

Keyboard Interactions

  • F8Moves focus to the notification viewport.
  • TabMoves among toast actions and close controls.
  • EscapeDismisses the currently focused toast.
  • Hover / FocusPauses the active timer; it also pauses on window blur and hidden tabs.

$.star.ui.toast.show() returns the created toast. Use dismiss() or clear() to remove notifications programmatically. The equivalent named actions are @ui.toast.show, @ui.toast.dismiss, and @ui.toast.clear.
