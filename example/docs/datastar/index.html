Datastar Integration

jQStar keeps localized browser behavior beside the HTML while the server can update signals and page regions through JSON, HTML, or Datastar server-sent events.

One protocol boundary: jQStar consumes Datastar-compatible events. Your server must generate SSE with @starfederation/datastar-sdk, never handwritten event strings.

Call the backend from HTML

Built-in request actions serialize the current public signals and interpret the response by its content type.

application.html 
<button data-on:click="@get('/items')">Refresh</button>

<form data-on:submit__prevent="@post('/items', { contentType: 'form' })">
  <input name="title" required />
  <button>Save</button>
</form>

GET places signals in a datastar query parameter. POST, PUT, PATCH, and DELETE use the documented JSON or form contract. Every request includes Datastar-Request: true.

Response behavior

Response jQStar result
application/json Deep-patch signals; a null value removes a signal.
text/html Morph elements by ID or the Datastar selector and mode headers.
text/event-stream Apply Datastar signal and element patches as they arrive.
204 No Content Complete the request without changing the application.

Generate streams with the official SDK

Terminal 
npm install @starfederation/datastar-sdk
server.ts 
import { ServerSentEventGenerator } from "@starfederation/datastar-sdk/node";

const read = await ServerSentEventGenerator.readSignals(request);
if (!read.success) {
  response.writeHead(400).end(read.error);
  return;
}

await ServerSentEventGenerator.stream(request, response, (stream) => {
  stream.patchSignals(JSON.stringify({
    count: Number(read.signals.count ?? 0) + 1,
  }));

  stream.patchElements('<li data-text="$count"></li>', {
    selector: "#feed",
    mode: "append",
  });
});

Enhancement after a patch

Inserted HTML is scanned immediately. New directives, bindings, component roots, named actions, and cleanup hooks work without calling .star() again. Outer morphs preserve matching elements, focused controls, unsaved values, and existing jQuery handlers. Use data-ignore-morph for a general subtree the server must not change. Use data-jqs-preserve when a live jQStar application root must survive the patch, and await $.star.whenEnhanced() before reading newly inserted directive or component DOM.

The repository's Component Lab includes real JSON, HTML, multipart, and official-SDK stream endpoints when run through the local proof server.
