jQuery ecosystem

jQStar builds on the real jQuery peer while keeping the roles of Migrate, UI, Mobile, Sizzle, and QUnit explicit. These decisions were reviewed against primary project sources on 3 September 2026 and expire on 3 March 2027.

Independent project: jQStar is an independent project. It is not affiliated with, sponsored by, endorsed by, or an official successor to the jQuery project or the OpenJS Foundation.

Current decisions

Project Reviewed release jQStar role
jQuery Core 4.0.0 The application-owned peer and runtime foundation.
jQuery Migrate 4.0.2 Temporary, application-owned upgrade diagnostics. Never bundled.
jQuery UI 1.14.2 External coexistence and migration source, not a foundation.
jQuery Mobile 1.4.1 last stable Design lessons and route-by-route migration. No runtime.
Sizzle 2.3.10 last stable No standalone integration. Selector behavior belongs to jQuery.
QUnit 2.26.0 Exact installed-package test consumer. No runtime dependency.

Boundaries

jquery is the sole peer at >=4.0.0 <5. $ is real jQuery and $name is a reactive signal. Similar component names do not promise Widget Factory, plugin, event, option, styling, or method compatibility. For the staged Migrate workflow, complete UI capability map, Mobile migration rules, naming, sources, and review process, read the repository policy. Existing UI applications can start with the jQuery UI migration guide.
