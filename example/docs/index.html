Introduction

jQStar adds reactive state, backend actions, and accessible UI behavior to ordinary server-rendered HTML. It uses the real jQuery instance rather than replacing it with a look-alike API.

Design philosophy: your backend generates HTML, jQStar enhances local interaction, and Datastar can stream server changes. No virtual DOM or duplicated browser router is required.

Install the package

jQStar 1.1 supports jQuery 4 and Node 24 or newer for package consumers and tooling. Review the complete compatibility contract before adopting an optional entry.

Terminal 
npm install jquery-star jquery

Import jQuery, install jQStar's root side effect, and include the optional default theme.

main.ts 
import $ from "jquery";
import "jquery-star";
import "jquery-star/ui.css";

$("#app").star();

Write reactive HTML

A data-signals root owns local state. Directive expressions can read and write signals and call the installed jQuery instance in the same expression.

counter.html 
<section id="counter" data-signals="{ count: 0 }">
  <button data-on:click="$count++; $(el).fadeOut()">
    Increment and disappear
  </button>

  <output data-text="$count"></output>
</section>

$ is real jQuery. $count is a reactive signal. They are deliberately two different things.

Boot a page-wide application

Use $.star.boot() when the document element is the application root. Use $(selector).star() for an incrementally enhanced region.

main.ts 
import $ from "jquery";
import "jquery-star";

$.star.boot();

Add source-owned components

The CLI copies editable native HTML into your application. The package supplies behavior and the compiled theme; your project owns the resulting markup.

Terminal 
npx jqstar init
npx jqstar list
npx jqstar add button dialog tabs toast
npx jqstar doctor
