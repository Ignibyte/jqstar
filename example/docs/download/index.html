Download

This site describes the jQStar 1.0.0 release candidate. A candidate receipt proves local packed bytes; it does not mean that version has been published to npm or tagged in Git.

Install the current npm release

Terminal 
npm install jquery-star jquery

npm resolves the currently published package. Check the returned version before relying on 1.0 behavior; this page does not claim that an unpublished candidate is available there.

Use a reviewed candidate tarball

A maintainer can provide the exact jquery-star-1.0.0.tgz named by the immutable candidate receipt. Verify both hashes before installation.

Terminal 
shasum -a 256 jquery-star-1.0.0.tgz
shasum -a 512 jquery-star-1.0.0.tgz
npm install ./jquery-star-1.0.0.tgz jquery

Package formats

The package contains ESM and CommonJS entries, a root UMD build for no-build applications, declarations and source maps, optional CSS, the jqstar CLI, registry recipes, and a self-hosted website archive. jQuery remains an external peer; it is not vendored.

Verify an authorized publication

Terminal 
npm view jquery-star@1.0.0 --json
git rev-parse v1.0.0^{commit}
gh release view v1.0.0 --json tagName,targetCommitish,isDraft,isPrerelease,url

Compare registry integrity, tag target, release assets, and receipt hashes. Publication, tagging, signing, and announcements require separate maintainer authorization.
