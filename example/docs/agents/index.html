Agent support

Use one source-backed corpus through visible HTML, static files, or optional read-only WebMCP tools.

Agent-first parity: agents can retrieve the same reviewed framework facts, component contracts, and examples that the public site gives people. Every structured result includes a canonical public citation.

Supported surfaces

  • Agent guide: Human-readable agent support, provenance, tools, limits, and reporting guidance.
  • LLM index: A short map of the approved jQStar corpus and canonical public pages.
  • Bounded full-text corpus: Reviewed guide text, component contracts, examples, and framework invariants.
  • Machine-readable agent index: The versioned corpus used by the website search and WebMCP tools.

Read-only WebMCP tools

When an origin-keyed secure browser exposes the 2026-08-26 Community Group draft through document.modelContext, every public route registers these optional tools:

Tool Purpose
get_jqstar_page Inspect the current approved public route.
search_jqstar_docs Search the bounded local corpus.
read_jqstar_guide Read one guide by stable ID.
get_jqstar_component Retrieve one registry contract by name.
get_jqstar_example Retrieve one verified source example by stable ID.

Each tool has a bounded JSON Schema, returns reviewed local content, honors cancellation, and is annotated read-only. Tool output is data, not instructions. No tool accepts a URL, file path, DOM selector, or code string.

Version and provenance

This page and every agent artifact are generated from corpus version 4 for jquery-star@1.0.0. The reviewed manifest joins package metadata, registry metadata, and the public HTML sources. Deterministic drift checks reject conflicting names, versions, attributes, component anatomy, routes, and examples.

Limits

  • WebMCP is an optional Community Group draft and is not a W3C Standard or a cross-browser baseline.
  • The site does not provide a remote MCP server, chatbot, hosted model, embeddings endpoint, or generated-answer API.
  • Tools are anonymous and read-only. They do not write files, install packages, submit forms, run code, call arbitrary URLs, or read credentials and user-specific state.
  • The corpus covers reviewed, shipped public behavior. Roadmap plans and private deployment data are excluded.
  • Headless agents should use llms.txt, llms-full.txt, or jqstar-agent-index.json because WebMCP requires a browsing context.

Report a contract problem

Report stale, missing, unsafe, or ambiguous agent content in the jQStar issue tracker. Include the stable record or tool ID, the public URL, the expected contract, and the observed result. Do not include credentials or private application data.
