jQStar · server-rendered application framework

Modern web applications.
Without the SPA.

A full-featured frontend platform for server-rendered applications that do not want to become single-page applications.

Keep the server in charge

Build a modern application without moving the application into the browser.

  • Keep routes, validation, permissions, and data on the server.
  • Keep HTML readable and useful before JavaScript runs.
  • Add reactivity and rich components where they are needed.
  • Update page regions through HTML, JSON, or Datastar streams.
  • Avoid JSX, hydration, virtual DOM ownership, and duplicated client routes.
  • Continue using existing backend templates and jQuery plugins.
  • Adopt it incrementally instead of rewriting the application.

What we are building for

A complete server-rendered development experience.

  1. An excellent server-rendered development experience.
  2. Predictable enhancement and cleanup after HTML replacement.
  3. Examples for PHP, Rails, Django, Node, and similar stacks.
  4. Strong no-build and modular-package support.
  5. Accessible components that solve real application workflows.
  6. Optional navigation and shared state without making them mandatory.
  7. Migration paths from ordinary jQuery, jQuery UI, and jQuery Mobile.

$ is real jQuery. $name is a reactive signal. Named actions move longer behavior back into JavaScript.
